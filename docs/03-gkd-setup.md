# GKD 部署

## 1. 安装

推荐方式：**用系统文件管理器安装**。

1. 把 `gkd.apk` 放到手机存储（如「下载」）。
2. 打开系统「文件管理」→ 找到 APK → 点击安装。
3. 如提示「允许文件管理安装应用」，选允许。

原因：ColorOS / realme UI 对 `adb install` 或第三方安装器安装的应用，可能限制无障碍服务。用系统文件管理器安装可避开这个限制。覆盖安装即可，不需要卸载。

---

## 2. 开启无障碍

1. 打开 GKD → 首页「服务状态」。
2. 点「无障碍未授权」→「开启无障碍」→「前往」。
3. 系统设置 → 无障碍 → 已下载的应用 → **GKD** → 开启。
4. 弹窗「要允许 GKD 完全控制你的设备吗？」→ 允许。
5. 返回 GKD，首页应显示「无障碍正在运行」。

如果首页显示「无障碍发生故障」，但功能其实正常，见 `04-verify.md` 第 3 节。

---

## 3. 添加订阅

GKD → 底部「订阅」→ 右下 `+`。

### 3.1 红果专属规则

```text
https://raw.githubusercontent.com/yaoyaolingling/hongguo-guanggao/main/gkd/hongguo-sub.json
```

包含 6 组：

| 组 | 作用 |
|---|---|
| 开屏广告 | 点「跳过」/ 穿山甲 `tt_splash_skip_btn` |
| 局部广告-阅读-底部卡片广告 | 点 X → 点「关闭此广告」 |
| 全屏广告-阅读-视频广告 | 横向滑动翻页 |
| 青少年模式 | 点「我知道了」 |
| 功能类-短剧页广告上滑持续重试 | 检测「上滑继续」后上滑 |
| 实验类-直播播放器与底部箭头上滑 | 默认关闭，可能误滑 |

建议只开前 5 组，实验组保持关闭。

### 3.2 全局开屏规则

```text
https://raw.githubusercontent.com/yaoyaolingling/hongguo-guanggao/main/gkd/gkd-global-splash.json
```

只有 1 组「开屏广告-全局」，`matchAnyApp: true`，对所有已安装 App 生效（不含系统界面与桌面）。

> 私有仓库时 raw 不可用，用 `tools/serve.sh` 起本地服务器，或把 JSON 放进手机用 GKD 本地导入。

---

## 4. 启用与检查

1. 订阅页点进刚添加的订阅。
2. 「全局规则」→「开屏广告-全局」→ 开关变蓝。
3. 红果订阅里确认各组的开关状态。
4. 订阅页顶部应显示「规则匹配已启用」。

---

## 5. 保活（ColorOS 必做）

1. 设置 → 电池 → 应用耗电管理 → GKD → 允许后台活动 / 无限制。
2. 最近任务卡片下拉 → 锁定 GKD。
3. GKD → 设置 → 保活策略 → 打开「常驻通知」。
4. 不要手动「强行停止」GKD，否则系统不会自动重新绑定无障碍。

---

## 6. 关于悬浮窗

GKD 执行规则不需要悬浮窗。悬浮窗只用于：

- 规则触发时的屏上提示；
- 「悬浮窗保活」（可选）。

系统拒绝 `SYSTEM_ALERT_WINDOW` 时：

- 不会出现任何悬浮窗（符合「不想看到悬浮窗」的需求）；
- 规则照常点击；
- 触发提示改走通知栏。
